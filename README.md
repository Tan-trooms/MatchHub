# MatchHub

A centered recruitment dashboard for applicant matching, committee assignment, and interview simulation.

View your app in AI Studio: https://ai.studio/apps/0515c658-ec2d-49cf-97a8-30512f530cdd

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
